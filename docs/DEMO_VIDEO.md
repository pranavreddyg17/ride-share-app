# 30-second GitHub demo

Record this in the **Practice workspace** so no pilot information appears in the video. Use a browser window at about 1440 × 900, hide personal browser tabs and notifications, and keep the cursor still between clicks.

| Time    | Screen                   | Narration / action                                                                                                                                                    |
| ------- | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0–3 s   | Sign-in screen           | “Kinetic Youth helps coordinators connect approved students with trusted high-school drivers.”                                                                        |
| 3–8 s   | Admin dispatch           | Open Practice workspace. “The coordinator sees today’s schedule, active trips, service-hour reviews, and issues that need attention.”                                 |
| 8–13 s  | Ride ledger              | Open **Rides** and select a completed sample ride. “Each ride keeps a timeline from request and assignment through pickup, drop-off, and completion.”                 |
| 13–18 s | Family trip view         | Switch to Family practice view and open an active ride. “Families can see the route, trip status, and pickup verification without seeing unnecessary driver details.” |
| 18–23 s | Driver trip view         | Switch to Driver practice view. “Drivers receive assignments, confirm pickup, and share foreground trip location while a ride is active.”                             |
| 23–28 s | Service hours            | Return to Admin → **Service hours**. “Service time runs from arrival at pickup to drop-off, including waiting, and stays pending until a coordinator reviews it.”     |
| 28–30 s | Excel export or dispatch | Hover over **Export Excel**. “Kinetic Youth also exports clean records for timesheets and program reporting.”                                                         |

## Recording settings

- Keep the video at **30 seconds or less**.
- Record at **1080p, 30 fps**. Export MP4 using H.264.
- Use captions or the narration above; avoid background music with copyright restrictions.
- Trim idle loading, sign-in transitions, and any practice data that looks like real participant information.

## GitHub placement

GitHub repositories do not reliably play an MP4 committed inside the repository README. After you create your GitHub repository, drag the completed MP4 into a GitHub issue or release description. GitHub will host it and give you an asset link. Replace the placeholder in the root README with that link.

Suggested title: **Kinetic Youth — 30-second pilot walkthrough**.
